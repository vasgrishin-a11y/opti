Подключение к PostgreSQL
Достаточно ввести логин и пароль — хост, порт и база уже подставлены. Поле «адрес backend» нужно, только если дашборд открыт не через npm start (двойной клик по файлу, Live Server, другой хостинг): укажите, где запущен backend — при file:// подставится http://localhost:3000. Вход запоминается в этом браузере на 4 часа: повторное подключение — из другой вкладки или после перезагрузки страницы — пройдёт без ввода пароля. Кнопка «Закрыть автосессию» стирает сохранённый пароль досрочно.
